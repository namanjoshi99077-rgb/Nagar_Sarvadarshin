==================================================
1. CORE PRODUCT VISION
==================================================

Nagar Sarvadarshin is a mobile-first AI civic intelligence platform.

A citizen should be able to:

1. Open the mobile application.
2. Tap "Report Issue".
3. Open the phone camera.
4. Capture a civic problem.
5. Automatically capture the user's current GPS location.
6. Optionally record voice/video.
7. Let AI analyze the evidence.
8. Automatically classify the civic issue.
9. Calculate severity and priority.
10. Search nearby/existing complaints.
11. Detect duplicate reports.
12. If the same problem already exists, attach the new report to the existing Civic Case.
13. Otherwise create a new Civic Case.
14. Automatically route the case to the correct municipal department.
15. Track the case.
16. Receive notifications when the case status changes.

The municipality/employee side should have a desktop/tablet-friendly command center where employees can:

- review Civic Cases
- review AI analysis
- approve/reject cases
- assign cases
- view live GIS map
- see transportation/mobility hotspots
- manage SLA
- update case status
- upload resolution evidence
- use AI-assisted resolution verification
- escalate overdue cases
- view analytics

CORE MESSAGE:

ONE PROBLEM.
ONE CIVIC CASE.
ONE COORDINATED RESPONSE.
